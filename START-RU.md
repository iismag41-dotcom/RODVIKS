# RODVIKS — запуск (Windows, без Docker)

## 1. Запустить PostgreSQL
```bat
C:\rodviks\start-db.bat
```

## 2. Запустить backend
```bat
cd C:\rodviks\backend
npm run dev
```
Сервер: http://localhost:3000 (должен ответить {"ok":true} на /health)

## 3. Установить APK на телефон
Файл: **C:\rodviks\android\app\build\outputs\apk\debug\app-debug.apk**

- Эмулятор Android Studio: просто перетащить APK в окно эмулятора, или `adb install app-debug.apk`
- Реальный телефон: скопировать APK, разрешить установку из неизвестных источников, установить.

## 4. Подключение к серверу (реальный телефон, без эмулятора)
1. Телефон и компьютер подключены к **одной Wi-Fi сети**.
2. IP этого компьютера в Wi-Fi: **192.168.101.12** (проверка: `ipconfig` → «Беспроводная сеть» → IPv4).
3. В приложении **на экране входа или регистрации** есть поле «Адрес сервера» — введите `http://192.168.101.12:3000`. Адрес сохранится при нажатии кнопки входа/регистрации.
4. Если оставить поле пустым — используется `http://10.0.2.2:3000` (адрес только для эмулятора; на реальном телефоне даст «Ошибка сети»).
5. Порт 3000 должен быть разрешён в брандмауэре Windows: при первом запуске node.exe Windows обычно спрашивает — «Разрешить доступ». Проверка с телефона: открыть в браузере `http://192.168.101.12:3000/health` — должно вернуть `{"ok":true}` (доступ проверен, сервер отвечает на этот адрес).

## 5. Проверка
1. Зарегистрируйте два аккаунта (username + email + пароль от 8 символов).
2. В поиске найдите второго пользователя по имени.
3. Откройте чат и обменяйтесь сообщениями — доставка в реальном времени.
